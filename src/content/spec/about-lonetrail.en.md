**Lonetrail** is a blog theme built on Astro, focused on reading experience and visual clarity.

### Design philosophy

The name comes from the Latin *Per Aspera, Ad Astra* — through hardships to the stars. A quiet table for thoughts in the middle of an information flood.

Three principles:

- **Restraint** — strip the decoration; let the writing lead
- **Order** — one typographic rhythm and one set of color tokens across every page
- **Completeness** — a clean interface that still does everything you need

### Tech stack

- **Framework**: Astro
- **Interactivity**: React + Tailwind CSS
- **Content**: Markdown / MDX
- **Search**: Pagefind
- **Comments**: Twikoo (optional)
- **Analytics**: Umami (optional)
