**Lonetrail** 是一个基于 Astro 构建的博客主题，关注阅读体验与视觉表现。

### 设计理念

名字取自拉丁语 *Per Aspera, Ad Astra*（循此苦旅，直抵群星），希望在信息洪流里留一张安静的桌子。

三条原则：

- **克制**——去掉一切可有可无的装饰，让内容成为主角
- **秩序**——统一的排版节奏和色彩 token，页面之间不打架
- **完整**——界面干净，但该有的能力一个不少

### 技术栈

- **框架**：Astro
- **交互**：React + Tailwind CSS
- **内容**：Markdown / MDX
- **搜索**：Pagefind
- **评论**：Twikoo（可选）
- **统计**：Umami（可选）
